# UI rules

Load the `frontend-design` skill for every design task, and the `shadcn` skill
before writing UI. Run `pnpm dlx shadcn@latest search` before hand-rolling a
component.

- **Base UI, not Radix.** Compose with the `render` prop, never `asChild`. A
  Base UI `Button` rendering a non-`<button>` needs `nativeButton={false}`; for
  a plain link styled as a button in `.astro`, use
  `class={buttonVariants({ … })}` on an `<a>`.
- `src/components/ui/` is generated by the shadcn CLI. Biome ignores it, and
  you edit it sparingly. `cn()` comes from the `cn` package (shadcn's
  clsx + tailwind-merge replacement), re-exported by `@/lib/utils`.
- **Semantic tokens only** (`bg-primary`, `text-muted-foreground`), never raw
  palette colours and no `dark:` classes: the site is light only. Markaryd green,
  defined in `src/styles/global.css`, must stay in step with
  `../mafk-mobie/src/constants/theme.ts`. The site's neutrals, Gran and Reflex are
  its own (docs/design.md, "Dagslistan"); on a Gran band use `surface-gran`.
- `className` is for layout, not for recolouring components. Use `gap-*`, not
  `space-x/y-*`; `size-*`, not `w-* h-*`; `cn()` for conditionals.
- Forms use `FieldGroup` + `Field`, with `data-invalid` on the field and
  `aria-invalid` on the control. Dialogs, sheets and drawers always have a
  Title (`sr-only` if hidden).
- **Hydration discipline**: public pages are `.astro` with zero client
  directives by default. Islands are small leaves, `client:visible` or
  `client:idle`. A shadcn component that never needs interactivity renders
  statically, with no directive. The admin's forms are plain POSTs, so their
  controls must work unhydrated: `NativeSelect`, a native checkbox,
  `Textarea` with `defaultValue`. Only the editor and the image uploader are
  islands (`client:only`).
- **The public site follows `docs/design.md`.** Its layout is `site.astro`
  (menu as a prop; it queries nothing), its type scale is the `type-*`
  utilities in `global.css`, and article and page bodies are styled by
  `src/styles/content.css` (`.content`), which the editor shares. Dates sit in
  a 7rem margin column from `md` up.
- **Swedish copy**, written for club members: plain, warm, no jargon. Dates
  use `sv-SE`.
- **Mobile first**: design at 360 px, touch targets ≥ 44 px, and no horizontal
  scroll.
- Verify visible changes with `pnpm preview` **in Zen**. The site is light
  only (docs/design.md, "Colour"); there is no dark theme to check.
